Cara Upload Gratis ke GitHub Pages (Dapat Link https://username.github.io/...):

  1. Buka github.com (login / daftar gratis), lalu klik tombol New Repository (beri nama misal monitoring-esp32, pilih Public, klik Create repository).
  2. Klik tulisan "uploading an existing file", lalu tarik file index.html ini ke dalamnya dan klik Commit changes.
  3. Buka menu Settings → Pages (di menu kiri) → pada bagian Branch pilih main lalu klik Save.
  4. Tunggu ~30 detik, link resmi https://username.github.io/monitoring-esp32/ siap dibuka di HP maupun Laptop dari mana saja!
